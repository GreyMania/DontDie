This is a WORK IN PROGRESS GAME. This game is not finished yet, I am still actively working on it to this day.
Do not complain that there is a bug that takes you to level 1 when you die. That is intentional. It is literally the gimmick of the game.

HOW TO SET UP:

For GBC/GBA/Emulator users:
Download a compiled version of the game from the Releases section, put it on your flashcart for GBC/GBA users, or just open it with your emulator for emulator users, and enjoy! Note that colors may not be too accurate but the game uses minimal colors and it looks fine in when tested in mGBA and GameYob for 3DS. Sound comes in and out on GameYob, but that's the emulator as far as I know. If you don't trust the precompiled roms, download the source code instead, and export the game yourself in GB Studio. (gb studio is free so you shouldn't have to pay a penny!)

For GB users:
Download the source code, and in GB Studio, DISABLE COLOR MODE, and export your modified version of the game as a ROM. Put it on your flashcart, and enjoy! Note that the game will (obviously) not be in color. And yes, you can distribute the ROM of the game to other people.

For Modding:
Yes, you can make mods of the game and distribute them. I may even try them out :)
